# GapHack

GapHack is a hackathon project that connects companies and cybersecurity specialists to discover and solve cybersecurity gaps together.

The platform allows companies to post security tasks or potential vulnerabilities, while cybersecurity users analyze them, submit findings, and build a public portfolio of their work.

## Problem

Many companies have cybersecurity gaps but cannot afford expensive security audits or bug bounty programs. At the same time, cybersecurity learners lack real-world problems to practice on and often do not have a place to showcase their work.

## Solution

GapHack creates a community ecosystem where:

- Companies post cybersecurity challenges or potential vulnerabilities.
- Cybersecurity users analyze tasks and submit findings.
- Submissions become part of the user's public cybersecurity portfolio.
- Companies reward useful findings with badges and recognition.

## Features

- User and company registration
- Cybersecurity task posting
- Thread-style solution submissions
- User profiles with portfolios
- Badge and reputation system
- Leaderboard for top contributors

## Tech STack
- VueJS
- FastAPI

## Goal

GapHack aims to create a collaborative cybersecurity ecosystem where companies can discover vulnerabilities and cybersecurity specialists can gain real-world experience.
